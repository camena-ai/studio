# v0 shell and themes implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A runnable `apps/web` whose `/` route matches the reference screenshot in light and dark, built on tokens and vendored shadcn/ui items in `packages/ui`, with a root `DESIGN.md` that Claude Design can ingest.

**Architecture:** `packages/ui` owns design tokens (`tokens.css`), the Tailwind v4 theme bridge (`globals.css`), vendored shadcn/ui Radix-flavour items and Studio's own presentational components. `apps/web` owns routing (TanStack Router, file routes), state (Effect Atom: theme override, composer draft, selected model) and the shell composition. `DESIGN.md` mirrors `tokens.css` and a test keeps them in agreement.

**Tech Stack:** React 19.3, Vite 8.3, Tailwind 4.3, TanStack Router 1.170, Effect 4.0.0-rc.117 + `@effect/atom-react`, `radix-ui`, `lucide-react`, `class-variance-authority`, `clsx`, `tailwind-merge`, `tw-animate-css`, Vitest 5 + jsdom, Biome 2.5.

## Global Constraints

- Every dependency version is exact, lives in the `catalog` of `pnpm-workspace.yaml`, and is at least 24 h old. New entries: `radix-ui: 1.6.7`, `lucide-react: 1.47.0`, `class-variance-authority: 0.7.1`, `clsx: 2.1.1`, `tailwind-merge: 3.7.0`, `tw-animate-css: 1.4.0`, `@testing-library/react` and `@testing-library/dom` (check `npm view` for a version older than 24 h).
- Licenses: MIT, Apache-2.0, BSD, ISC, MPL-2.0 only. No font packages (Geist and Inter are OFL). System font stack.
- Vendored shadcn files are unchanged except the import rewrite `from "cn"` → `from "@studio/ui/lib/utils"` and `@/components/ui/x` → `@studio/ui/components/ui/x`, `@/hooks/use-mobile` → `@studio/ui/hooks/use-mobile`. They carry a REUSE annotation (MIT, shadcn).
- All UI state in Effect Atom. No React context for theme, no other state library.
- No message content is ever logged. v0 has no messages.
- Biome formatting: double quotes, no semicolons, trailing commas, 100 columns. Run `pnpm lint:fix` before each commit.
- Copy: placeholder "Ask Studio anything", hint "Choose local or sign in", tab title "New chat".
- The vendored sources were generated by `shadcn@4.21.0` with `-b radix -p nova` into the scratch project `<scratchpad>/shadcn-scratch/src` (button, textarea, tooltip, dropdown-menu, separator, sheet, skeleton, input, kbd, sidebar, hooks/use-mobile).
